# /phase

Read docs/PHASES.md and give a full phase summary.

Show:

1. **Current phase** number and name
2. **Phase goal** (one sentence)
3. **Tasks in this phase**: [x] done, [ ] remaining — with brief description of each
4. **Blockers or prerequisites** for remaining tasks in this phase
5. **Phase completion %**: X of Y tasks done
6. **When this phase is complete**: what the next phase starts with

If all tasks in the current phase are done, declare the phase complete and show what Phase N+1 starts with.
